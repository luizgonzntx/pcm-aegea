Configuração da Infraestrutura Supabase

Para que o sistema web funcione de forma real e integrada com as equipes de campo, conecte sua conta do Supabase. O banco de dados guarda os equipamentos e usa a base oficial de plantas apenas para localizar cada registro.

Bucket Público de PDFs: 1. Vá em **Storage** no seu Supabase.
2. Crie um bucket público com o nome catalogos.
3. Suba os PDFs técnicos das bombas.
4. O leitor integrado usará as chaves para abrir os arquivos diretamente.

Como a localização funciona

Ao cadastrar o equipamento, selecione uma planta oficial. O SICAB preenche automaticamente município, regional e gerência. Depois, essas informações ficam disponíveis para consulta e filtros na aba Equipamentos.

A base de plantas é somente leitura: não há cadastro, edição ou exclusão de plantas nesta aplicação.
