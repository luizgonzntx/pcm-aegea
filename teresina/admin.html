Administração da base PCM

Atualização administrativa

Esta área não aparece no painel operacional. Somente um membro com perfil ADMIN pode publicar uma nova base no Supabase.

ÁREA RESTRITA

Publicar atualização da base

Selecione os cinco arquivos XLSX: sistemas, ordens, itens, medidas e notas de parada. A validação acontece no navegador; a gravação só ocorre depois de sua revisão e confirmação.

A publicação substitui as cinco bases. As ordens com `Parada = X` são contadas uma única vez por ordem e planta, usando a data da nota; isso representa histórico de ocorrências, não uma indicação de que a planta está parada agora. Se alguém atualizar antes de você, o controle de revisão bloqueia a gravação para evitar sobrescrever dados novos.
